# Site — Eduardo R. K. Lima · Perito e Assistente Técnico Contábil

Landing page única (assistência técnica em cálculos trabalhistas para advogados).
HTML/CSS/JS puro, sem build. Hospedagem: Netlify.

## Como atualizar
Edite `index.html` (CSS e JS estão embutidos) e faça `git push` — o Netlify publica sozinho.

## Onde trocar dados
Procure por comentários `ALTERAR` no `index.html`: contato (WhatsApp/e-mail/Instagram),
imagens (`assets/img/`), Google Analytics e Search Console.
